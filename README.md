# Alpha Engine

Multi-market, multi-strategy signal engine. Each market runs its own pipeline, backtests strategies by market regime, selects regime-specific optimised params, and exports results to a local web viewer.

Markets: Thailand SET, US equities, AU ASX, crypto, commodity

Strategies: Pivot Breakout, Trendline Breakout, Pullback Buy, Reversal, BB Squeeze, MA Cross, Narrow Range

## Workflow (monthly cadence)

```
regime  →  regime-optimise  →  chart-export
```

Run everything in one command:

```bash
python run.py th run-all
```

Or step by step:

```bash
python run.py th regime           # 5yr regime discovery
python run.py th regime-optimise  # exit-param optimisation on PASS pairs
python run.py th chart-export     # export results to web viewer
```

## Quick start

## Web viewer

After `chart-export`, start the viewer:

```bash
python run.py th serve
# → http://localhost:8000
```

Pages:
- **Overview** — 5yr optimised performance table (Calmar, DD, WR, yearly returns per strategy×regime) + regime grid
- **Strategy detail** — parameters, annual returns, 5yr trade history by year and symbol
- **Symbol chart** — 5yr candlestick with volume, indicators, and trade entry/exit markers

## How it works

```
benchmark regime labels (SMA50/200)
        ↓
all strategies backtested 5yr by regime
        ↓
PASS pairs selected (calmar ≥ 0.5)
        ↓
signal-param × exit-structure × filter grid (36 combos per pair)
        ↓
best params saved to DB
        ↓
chart-export generates docs/chart_data.json
```

Two details that matter:

- `regime` and `regime-optimise` must use the same saved regime boundaries (read from DB).
- `chart-export` uses optimised params from DB — always run `regime-optimise` before `chart-export`.

## Optimisation grid

Per passing strategy×regime pair, 36 combos tested:

| Dimension | Values |
|---|---|
| Signal param | strategy-specific (swing lookback, KC mult, RSI threshold, MA periods, etc.) |
| Exit structure | original (full TP1) · tp1_50pct+EMA10 trail · tp1_30pct+TP2+EMA10 trail |
| RSM filter | off · ≥75 (top-25% relative strength) |
| STR filter | off · ≤4×ATR above SMA50 (blocks overextended entries) |

## Filter stack

| Filter | Param | Description |
|---|---|---|
| Trend | `trend_sma_period` | Close must be above the configured SMA. |
| Volume | `rvol_min` | Relative volume vs 20-day average. |
| Stretch | `str_max` | Blocks entries extended >N×ATR above SMA50. |
| RS Momentum | `rsm_min` | Relative strength vs benchmark universe. |

## Exit structure

| Step | Condition | Action |
|---|---|---|
| 1 | Stop loss hit | Full close |
| 2 | TP1 hit | Partial exit (configurable %) |
| 3 | TP2 hit | Partial exit of remainder |
| 4 | EMA exit | Exit remainder on close below EMA after TP1 |

Partial exits for the same position are grouped by `position_id` — counted as one trade.

## Database

Default local SQLite:

```
alpha_engine_dev.db
```

Override:

```bash
DATABASE_URL=postgresql://user:pass@host/dbname python run.py th run-all
```

Key tables: `regime_labels`, `regime_map`, `regime_optimise`, `strategy_params`

## Adding a strategy

1. Create `strategies/my_strategy.py`
2. Subclass `Strategy`, register with `@StrategyRegistry.register`
3. Implement `scan(df, params) -> list[Signal]`
4. Include filter params: `rvol_min`, `rsm_min`, `str_max`
5. Run `python run.py th regime` — confirm it appears in the report
